# Je suis bloqué

Réponds avec le cas qui correspond. Donne le bouton exact à chercher. Si aucun cas ne colle, dis que ce n'est pas dans le guide et oriente vers un administrateur.

## Le bouton est grisé ou absent

**Créer un devis**, **Créer une situation**, **Gérer les sous-traitants** ne marchent pas si le chantier est **En attente**, **Terminé** ou **Facturé**.

Ouvrir la fiche, changer le statut pour **En Cours**, recommencer. **Terminé** et **Facturé** se remettent en **En Cours** depuis la fiche si le chantier reprend.

**Éditer en avenant** n'apparaît pas sur un devis de chantier. C'est voulu : les travaux supplémentaires partent d'un autre devis.

**Generer PDF** n'existe qu'une fois le rapport enregistré. D'abord **Valider le rapport**, rouvrir le rapport, puis **Generer PDF**.

**Sauvegarder** les montants fournisseur est désactivé en mode **Global**. Choisir un mois dans **Mois** et **Année**.

## Mot de passe oublié

Le lien **Mot de passe oublié ?** ne fait rien. La case **Rester connecté** non plus. Un administrateur réinitialise le mot de passe : **Admin → Utilisateurs**, icône clé sur la ligne.

## Je ne vois rien après la connexion sur le téléphone

L'accueil affiche **Aucun accès configuré** si aucun espace n'est coché. Un administrateur ouvre **Admin → Utilisateurs**, **Accès mobile (PWA)**, et coche **Rapports** et/ou **Drive**. Un compte staff voit déjà tout.

Le menu **Collaborateur** n'existe pas sur téléphone. Clients, fournisseurs et sous-traitants se gèrent sur ordinateur.

## Document déjà existant

Un devis ne se transforme qu'une fois : facture, avenant, ou CIE. Le message **Document déjà existant** veut dire que c'est déjà fait. Ouvrir **Liste Facture** ou **Liste Devis** pour retrouver le document, au lieu d'en créer un deuxième.

## Conflit de fichier dans le Drive

Deux fichiers portent le même nom dans le même dossier. La fenêtre **Conflit de fichier détecté** propose **Remplacer le fichier existant** (l'ancien part dans **Historique**, 30 jours) ou **Enregistrer sous un nouveau nom**.

## Je ne trouve pas le chantier

**Chantier → Récap Chantier**, loupe **Changer de chantier**, ou la page **Liste des chantiers** (elle n'est pas dans le menu) et le champ **Rechercher un chantier**. Le **Récap Chantier** n'affiche qu'un chantier à la fois.

Un appel d'offres **En attente** ou **Refusé** n'est pas encore un chantier. Le transformer seulement s'il est **Validé**.

## La ligne de dépense ne se modifie pas

Sur l'écran d'une agence, les badges **Planning**, **Primes**, **Pointage** et **Sous-traitant** viennent d'ailleurs. On ne les édite pas ici. Corriger le planning, la prime, le pointage ou l'ajustement du **Tableau Sous-Traitant**.

## Le rapport ne part pas en PDF

Le rapport doit être enregistré. Le PDF Vigik+ exige la photo de la platine. Le PDF d'intervention exige la signature. Un brouillon du serveur se rouvre en cliquant la ligne, il n'a pas de pastille de statut.

## Ça ne correspond à aucun de ces cas

Dis-le clairement. Propose d'en parler à un administrateur pour un accès, un mot de passe ou un rôle. Ne propose pas un bouton qui n'est pas dans ce fichier.
