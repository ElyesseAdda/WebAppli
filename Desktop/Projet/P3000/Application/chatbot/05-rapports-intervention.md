# Rapports d'intervention

Le pas à pas ordinateur et téléphone (types, statuts, Vigik+, signature, brouillon, PDF) est dans `12-collaborateurs-et-rapports.md`. Résumé :

## Ordinateur

**Où :** **Documents → Liste document → Rapports d'intervention**. Titre **Rapports d'intervention**. Bouton **Nouveau rapport**.

Deux types : **Rapport d'intervention** et **Vigik+**.

**Filtres :** **Résidence**, **Type de rapport**, **Titre**, **Date de création du rapport**, **N° rapport**. On peut masquer les terminés (c'est le réglage de départ) et filtrer les rapports « devis à faire ».

**Statuts :** **Brouillon**, **Brouillons** (brouillon enregistré sur le serveur), **A faire**, **En cours**, **Terminé**.

**Sur une ligne :** modifier, supprimer, PDF, changer le statut, gérer **devis à faire** ou lier un devis déjà fait.

Un brouillon serveur se reprend depuis la ligne **Brouillons**.

## Formulaire

Titres : **Nouveau rapport d'intervention**, **Nouveau rapport Vigik+**, ou **Modifier le rapport**.

- **Retour** vers la liste.
- **Valider le rapport**.
- Sur un rapport déjà créé : **Generer PDF** (orthographe affichée telle quelle).

Champs selon le type : technicien, résidence, prestations, signatures, photos (Vigik), **Devis à faire** / **Devis fait**. Les photos peuvent rester dans le navigateur tant que le rapport n'est pas validé. Un brouillon serveur peut être promu en rapport définitif.

Les rapports d'un chantier se consultent aussi depuis la fiche chantier.

## Téléphone

Espace **Rapports** sur l'accueil mobile (si l'administrateur a coché **Rapports d'intervention** dans les accès mobile, ou si le compte est staff / superuser).

Barre **Rapports d'intervention**. En bas : **Rapports** et **Nouveau**. Le formulaire est le même, avec le bouton d'enregistrement en bas d'écran.

Questions : « créer un rapport », « reprendre un brouillon », « différence intervention et Vigik+ », « je ne vois pas Rapports sur le téléphone ».
